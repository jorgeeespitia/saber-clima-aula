# Datos

La base no se incluye en este repositorio.

1. Descargue "Pruebas Saber 3°, 5°, 7°, 9° (2022)" desde DataIcfes:
   https://www.icfes.gov.co/investigaciones/data-icfes/
2. Guarde el archivo `Prueba_Saber_3579_2022.txt` en esta carpeta o en otra ruta.
3. Indique la ruta en el cuaderno (variable `SABER_DATA`) o en `stata/replica.do` (global `datos`).

Cite la fuente: Icfes, DataIcfes, Repositorio de Datos Abiertos.
